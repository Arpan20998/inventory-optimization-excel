# Inventory-optimization-excel

# Project Objective

To simulate demand variability and calculate optimal Safety Stock and Reorder Point (ROP) using Excel.

# Tools Used

Excel



# Steps

Generated random demand using RAND() and RANDBETWEEN(bottom, top)

Simulated monthly demand variability

# Calculated:

Average demand

Standard deviation

Used service level to calculate Z-score using NORMSINV() function

Calculated Safety Stock

Calculated Reorder Point
